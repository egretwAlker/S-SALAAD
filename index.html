Abstract

Large models increasingly need to run on the device itself. Unreliable connectivity, communication delays and privacy requirements make the cloud a poor fit for many applications, so models must fit into limited memory and still run fast on local hardware.

Fewer parameters do not automatically mean faster inference. Learning sparse-plus-low-rank weights lets a single checkpoint be compressed to any memory budget. But when the sparse part is unstructured, indexing overhead and irregular memory access can erase the expected speedup.

S-SALAAD learns sparsity that hardware can actually use. During training, every weight matrix is learned as a low-rank part plus a structured sparse part, such as blocks, rows, columns or N ⁣: ⁣MN\!:\!MN:M patterns. Budget-aware compression and dedicated CPU and GPU kernels then turn that structure into real savings, from one checkpoint across all memory budgets.

The result: elastic, smaller and faster models. On Llama2 and Qwen3, in both pretraining and distillation, S-SALAAD advances the Pareto frontier in perplexity, memory and latency on multiple hardware platforms.
